隐私边界

  • 资料保存在扩展本地存储或扩展目录内置 JSON 中。
  • 扫描、匹配和填写都在当前浏览器页面内执行。
  • 插件不会自动点击保存、提交、签名、声明确认或上传附件。
  • 导出备份会生成一个本地 JSON 文件，请不要把包含个人资料的文件夹发给别人。
